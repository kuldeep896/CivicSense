# CivicSense 🚀

A smart civic issue reporting app built using React Native and Node.js.

## Features
- Report public issues
- Upvote issues
- Priority-based system
- Real-time issue listing

## Tech Stack
- React Native
- Node.js
- Express
- MongoDB

## How to run

### Backend
cd backend
npm install
npm start

### Frontend
npm install
npx react-native run-android
